# Frontend Custom Hooks

This directory houses React hooks for managing state and side effects.

## Intended Hooks

* **`useWebcam.ts`**: Handles camera media stream lifecycle, device selections, and frame grabbing.
* **`useWebSocket.ts`**: Reusable hook for managing WebSocket connection, reconnect logic, message serialization, and listeners.
* **`useGestureCanvas.ts`**: Keeps track of active brush states, stroke coordinates, and canvas sizing.
