# Frontend Components Directory

This directory contains reusable React UI components.

## Recommended Structure

* **`canvas/`**: Contains Canvas/WebGL overlay components (e.g. `DrawingCanvas.tsx`, `WebcamPreview.tsx`, `CursorOverlay.tsx`).
* **`dashboard/`**: Contains analytics, workspace management lists, and settings drawers.
* **`ui/`**: Core base components (buttons, inputs, dialogs, modals).
